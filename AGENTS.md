# Horse Payo — AGENTS.md

## Stack

- **Framework:** Astro v4 (SSG)
- **Estilos:** Tailwind CSS v3
- **Hosting:** Netlify

## Comandos

```bash
npm run dev      # desarrollo local (localhost:4321)
npm run build    # build de producción → dist/
```

## Regla de commit

Después de **cada cambio**, ejecutar en orden:

```bash
git add .
git commit -m "descripción clara del cambio en español"
git push
```

No acumular cambios sin commit. Cada modificación merece su commit atómico con mensaje descriptivo.
